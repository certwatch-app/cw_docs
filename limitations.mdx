## Current Limitations

| Limitation | Details | Status |
|------------|---------|--------|
| **Internal certificates** | Only publicly accessible endpoints are supported | Agent coming soon |
| **mTLS endpoints** | Client certificate authentication not supported | Contact us for enterprise |
| **Connection timeout** | 10 second limit for certificate retrieval | Contact us if you need more |
| **API key access** | API keys for external integrations not yet available | Coming soon |
| **Discord notifications** | Not yet available | Coming soon |
| **CT log monitoring** | Certificate Transparency monitoring not available | Coming in future release |
| **IP whitelisting** | We use dynamic IPs, no static list available | Contact us for firewall rules |

---

## Rate Limits

These limits help ensure reliable service for all users.

| Operation | Limit | Window |
|-----------|-------|--------|
| Manual certificate checks ("Check Now") | 10 | per minute |
| Test notifications | 5 | per minute |
| API requests | 100 | per minute |

If you hit a rate limit, wait a moment and try again. Rate limits reset every minute.
