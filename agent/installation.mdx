## Quick Install (Linux/macOS)

The fastest way to install:

```bash
curl -sSL https://certwatch.app/install.sh | bash
```

This script:
- Detects your OS and architecture
- Downloads the latest release from GitHub
- Installs to `/usr/local/bin/cw-agent`
- Verifies the installation

<Tip>
  You can also specify a custom install directory: `INSTALL_DIR=/custom/path curl -sSL https://certwatch.app/install.sh | bash`
</Tip>

## Package Managers

### Homebrew (macOS/Linux)

```bash
brew install certwatch-app/tap/cw-agent
```

### Go Install

```bash
go install github.com/certwatch-app/cw-agent/cmd/cw-agent@latest
```

<Note>
  Requires Go 1.24 or later.
</Note>

## Docker

```bash
docker pull ghcr.io/certwatch-app/cw-agent:latest
```

## Kubernetes (Helm)

Deploy using our official Helm chart from the OCI registry:

### Quick Install (Testing)

```bash
helm install cw-agent oci://ghcr.io/certwatch-app/helm-charts/cw-agent \
  --set agent.name=my-cluster \
  --set apiKey.value=cw_your_api_key_here \
  --set certificates[0].hostname=api.example.com
```

<Warning>
  When using `apiKey.value`, the key is stored in Helm release history. Use `apiKey.existingSecret` for production deployments.
</Warning>

### Production Install (Recommended)

```bash
# Create a secret for your API key
kubectl create secret generic cw-agent-api-key \
  --from-literal=api-key=cw_your_api_key_here

# Install the chart
helm install cw-agent oci://ghcr.io/certwatch-app/helm-charts/cw-agent \
  --set agent.name=my-cluster \
  --set apiKey.existingSecret.name=cw-agent-api-key \
  --set certificates[0].hostname=api.example.com
```

## Manual Download

Download pre-built binaries from the [GitHub Releases](https://github.com/certwatch-app/cw-agent/releases) page.

| Platform | Architecture | Download |
|----------|--------------|----------|
| Linux | x86_64 (amd64) | `cw-agent_X.X.X_linux_amd64.tar.gz` |
| Linux | ARM64 | `cw-agent_X.X.X_linux_arm64.tar.gz` |
| macOS | x86_64 (Intel) | `cw-agent_X.X.X_darwin_amd64.tar.gz` |
| macOS | ARM64 (Apple Silicon) | `cw-agent_X.X.X_darwin_arm64.tar.gz` |
| Windows | x86_64 | `cw-agent_X.X.X_windows_amd64.zip` |

### Manual Installation Steps

<Steps>
  <Step title="Download">
    ```bash
    curl -LO https://github.com/certwatch-app/cw-agent/releases/latest/download/cw-agent_X.X.X_linux_amd64.tar.gz
    ```
  </Step>
  <Step title="Extract">
    ```bash
    tar -xzf cw-agent_X.X.X_linux_amd64.tar.gz
    ```
  </Step>
  <Step title="Install">
    ```bash
    sudo mv cw-agent /usr/local/bin/
    sudo chmod +x /usr/local/bin/cw-agent
    ```
  </Step>
  <Step title="Verify">
    ```bash
    cw-agent version
    ```
  </Step>
</Steps>

## Verify Installation

After installation, verify the agent is working:

```bash
cw-agent version
```

Expected output:
```
CertWatch Agent v0.5.3

  Version     v0.5.3
  Commit      abc1234
  Build Date  2025-01-01
  Go Version  go1.24.0
  Platform    linux/amd64
```
